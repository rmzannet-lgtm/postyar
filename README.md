# پُستیار – اپلیکیشن آفلاین مدیریت مرسولات (اندروید)

ثبت مرسوله، تحویل (تک‌مرسوله و چندمرسوله)، برگشت، جستجو، گزارش اکسل، رسید A4 با سربرگ، پشتیبان‌گیری ZIP، تایپ صوتی فارسی و اسکن بارکد با دوربین؛ **همه کاملاً آفلاین**.

> ⚠️ این پروژه در محیط من (بدون اینترنت و بدون Android SDK) **ساخته و روی گوشی تست نشده است**. اولین ساخت روی GitHub ممکن است به یک اصلاح کوچک نیاز داشته باشد؛ متن خطای Actions را برایم بفرستید تا درستش کنیم.

## ساخت APK با GitHub (بدون نصب Android Studio)

1. در GitHub یک مخزن (Repository) خصوصی بسازید.
2. محتوای همین پوشه را (نه خود ZIP) در آن آپلود کنید. حتماً پوشه `.github` هم آپلود شود.
3. به تب **Actions** بروید. workflow با نام **Build Android APK** با هر push اجرا می‌شود (یا دکمه *Run workflow* را بزنید).
4. بعد از حدود ۵ تا ۱۰ دقیقه، در پایین صفحه اجرا، بخش **Artifacts** فایل `postyar-debug-apk` را دانلود کنید.
5. فایل ZIP را باز کنید و `app-debug.apk` را روی گوشی نصب کنید (اجازه «نصب از منبع ناشناس» را بدهید).

### نسخه Release امضاشده (اختیاری)
اگر خواستید APK امضاشده بسازید، در *Settings → Secrets and variables → Actions* این چهار Secret را بسازید:
`KEYSTORE_BASE64` (فایل keystore به صورت base64)، `KEY_ALIAS`، `KEYSTORE_PASSWORD`، `KEY_PASSWORD`.
با تنظیم آن‌ها، workflow خروجی `postyar-release-apk` را هم می‌سازد.

## ساخت روی کامپیوتر خودتان
نیازمندی‌ها: Node 20، JDK 17، Android SDK (یا Android Studio).
```bash
npm install
npm run build:www        # کپی کتابخانه‌ها و فونت به www/vendor
npm run android:add      # ساخت پروژه اندروید + افزودن مجوزها
npm run android:icons    # آیکن و اسپلش
npm run android:debug    # خروجی: android/app/build/outputs/apk/debug/app-debug.apk
# یا:  npm run android:open   (باز کردن در Android Studio)
```

## ساختار پروژه
| مسیر | توضیح |
|---|---|
| `www/index.html` | کل رابط و منطق اپ (همان پیش‌نمایشی که تأیید کردید، بدون داده نمونه) |
| `www/native.js` | پل بومی: اسکنر ML Kit، تایپ صوتی، ارسال فایل، دکمه بازگشت |
| `scripts/vendor.js` | کپی SheetJS، JSZip و فونت وزیرمتن داخل اپ (برای آفلاین بودن) |
| `scripts/patch-android.js` | افزودن مجوز دوربین/میکروفون و تنظیم minSdk |
| `.github/workflows/build-apk.yml` | ساخت خودکار APK |
| `assets/` | آیکن و اسپلش (قابل جایگزینی با لوگوی خودتان؛ همان نام‌ها و اندازه ۱۰۲۴ و ۲۷۳۲) |

## نکات مهم
- **ذخیره داده:** اطلاعات مرسولات در حافظه داخلی اپ (localStorage)، و رسیدها در IndexedDB ذخیره می‌شوند. ظرفیت بخش اطلاعات چند هزار مرسوله است. اگر حافظه پر شود پیام می‌دهد. با «پاک‌کردن داده‌های اپ» یا حذف اپ، همه چیز پاک می‌شود. پس مرتب **پشتیبان ZIP** بگیرید (تنظیمات ← پشتیبان کامل).
- **ارسال و ذخیره فایل** (رسید، پشتیبان، اکسل) از منوی اشتراک‌گذاری اندروید انجام می‌شود. برای ذخیره روی گوشی گزینه «Files / ذخیره» یا درایو را انتخاب کنید؛ برای روبیکا همان‌جا روبیکا را بزنید.
- **تایپ صوتی فارسی** از موتور گفتار خود گوشی (Google) استفاده می‌کند. بدون اینترنت فقط با دانلود بسته زبان فارسی آفلاین در تنظیمات گوگل کار می‌کند.
- **اسکن بارکد** با ML Kit و بدون اینترنت انجام می‌شود (مدل داخل اپ است).
- دسترسی **اینترنت** برای اپ لازم نیست و اطلاعات هیچ‌جا ارسال نمی‌شود.
- اسم، کد ملی و تاریخ تولد اطلاعات شخصی هستند؛ فایل‌های پشتیبان را امن نگه دارید.

## ایده‌های بعدی
انتقال دیتابیس به SQLite، برش خودکار لبه‌های رسید (اسکنر سند ML Kit)، قفل رمز یا اثر انگشت، سطل بازیافت.
